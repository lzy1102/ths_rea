## 2. 已实锤证据

### 2.1 统一登录请求（客户端日志原文，captures/HexinHttp.2026-10-14.log）

```
GET http://auth.10jqka.com.cn/verify2?reqtype=do_rsa&type=get_pubkey
GET http://auth.10jqka.com.cn/verify2?reqtype=unified_login
     &account=<RSA密文b64>&passwd=<RSA密文b64>&rsa_version=default_5
     &imei=00000000000000000000000000000000&msg=1&ta_appid=2020063035285685
     &did=00000000000000000000000000000000&dpass=<RSA密文b64>&ukey=<32hex>
     &uver=E029.60.71.0088&ttype=PC
→ 会话落 cookie: http://upass.10jqka.com.cn/docookie2.php?userid=100000000
     &sessionid=143a2e4ea43dd7552da199fb89a144c69&signvalid=2026120908
（日志时间戳为 UTC，+8 为本地时间）
```

要点: account/passwd/dpass 都是 RSA 密文（128 字节 → 1024 位密钥），rsa_version=default_5。

### 2.2 下单报文（xiadan 内存 dump 反汇编实锤）

```
cmd=xd_mairu\ncode=%s\nprice=%s\namount=%s\nlock=%s\nrelmarket=%s\ndzh=1\nrelmarket=%d\nuserkey=%s\n
```
- 命令集: xd_mairu / xd_maichu / xd_dmdm / cmd_qu_zijin / tjdd_upload_wt / tjdd_chedan / tjdd_order / tjdd_cx_dd / tjdd_cx_gpxx / tjdd_extend / tjdd_change
- 字段池: preuserkey / userkey_list / baseprice / htbh / czlb / 买一价/卖一价 等

### 2.3 未注册账号拦截 (gate)

消息表位于 VMProtect 段 0x31ca3xx~0x31ca5xx（"系统检测到您现在还不是同花顺注册用户…"、"先绑定手机号"、"去绑定" 等按钮），显示代码 0x156dbd6 附近。
