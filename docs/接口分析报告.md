# 同花顺客户端接口分析报告

> 分析目标: 同花顺 Linux(麒麟)版 `cn.com.10jqka_kylin_2.9.1.2_amd64.deb` + Windows 版 `THS_v9.60.71_GOVERN_20260922.exe`
> 工具: REA/.NET 静态分析、ilspycmd、innoextract、自定义 PE/字符串扫描
> 用途: 学习研究、互操作性分析。交易类接口仅限本人合法账户、合规前提使用。

## 0. 总体结论

| 客户端 | 架构 | 行情接口 | 下单接口 |
|---|---|---|---|
| 麒麟版 (.deb) | .NET 5 (Avalonia) + CEF | GMS 协议 + HTTP 接口, 完整可静态分析 | **无**（交易按钮为空实现，`HevoNext.Page:14268`） |
| Windows 版 (exe) | C++ 原生 + 新 .NET 栈 (HevoSpace) + CEF | 原生行情引擎 + 新栈 HTTP/GMS | **有**: xiadan.exe(独立下单)、券商委托程序、embeddedtrade.dll、CTP 期货 |

# 一、行情接口

## 1.1 GMS 协议（核心行情通道）

架构（`decompiled/CSharpGMS/`）:

- 原生动态库 `hxsdk` 实现会话与传输；`CSharpGMS` 是 P/Invoke 封装
  - `GmsSharp.Initialize(GmsSetting{GmsHxSdkPath,...})`
  - `SessionClient.Connect(ServerInfoModel)` → `InitAuth` → `SendRequest(ushort requestId, string body, IntPtr ctx)`
  - `SendPushMessage(requestId, body)`、`SetAuthInfo`、`ConnectSessionAsync`(native)
- **线格式: requestId(ushort) + JSON body**（`Hevo.Api.Quotes:27995`）
- 服务类型 `ServiceTypeV4`（同文件）: `Login=0, BasicQuotes=10, Sort=12, SnapshotSubscribe=51, PushMsgs=1000`
- `hxsdk` 在 Windows 客户端对应 `HevoSpace/Hexin.NetCore.Engine.dll`（DualCLR 桥接旧引擎）

## 1.2 请求目录（全量表）

来源: `Hevo.Api.Quotes.dll` 内嵌资源 `Data.RequestTypeV2Data.xml` → 已导出:

- `docs/RequestTypeV2Data.xml`（101 条, 22 条订阅）
- `docs/request_types.md`（整理表格）
- `docs/RequestTypeV3Data.xml`（method 型新接口）

请求体示例（`RealtimeV4`, `Hevo.Api.Quotes:240`）:

```json
{"req": {"code_list": [{"market": "...", "code": "..."}],
         "trade_class": "...", "data_fields": ["25","10","..."],
         "open_type": "...", "need_order_book": true, "lang": "..."}}
```

推送（`GenericSubscribePushData`）: `{data: [{field_id: value,...}]}`，字段 id 即 QuoteField id。

# 二、下单接口（Windows 版）

> 麒麟版无下单。Windows 版下单由多条通道组成，以下为静态分析所得。

## 2.1 独立下单程序 `xiadan.exe`（86MB, VS2022, CEF 界面）

### 服务器端点

| 端点 | 用途 |
|---|---|
| `http://wt.10jqka.com.cn/wt?reqtype=wt_query_qs&service_type=1&wt_device=PC&app=pc` | **委托网关（新）** |
| `http://wt.10jqka.com.cn:80/wt` | 委托网关 80 口 |
| `http://trade.10jqka.com.cn:8088/verify` | 交易校验 |
| `http://218.94.93.90:8004/auth?`、`218.94.93.91:8004/auth?` | 老委托通道 |
| `http://127.0.0.1:8086/auth?` | 本地回环（本机新浪/券商桥） |
| `http://xdres.10jqka.com.cn/...` | 下单页面/资源/文档 |

### 登录与 RSA

```
%s?reqtype=do_rsa&type=get_pubkey
%s?reqtype=unified_login&account=%s&passwd=%s&rsa_version=%s&imei=%s&ta_appid=2022021835675725
```

`reqtype` 全表: `unified_login`, `do_rsa`, `hxinfo`, `wt_query_qs`, `query_wt`, `query_wt_user`, `modify_wt_user`, `query_qs`, `verify(datatype=verify)`。

### 会话/响应帧模板（字符串常量）

```
&si=%0x&qsid=%s&dlzh=%s&yybrid=%s&sa=%s&sp=%d&cv=%s&ret=%d&key1=%s&key2=%s&len=%d&data=%s
key1=%s&key2=%s&len=%d&data=%s
nType=0x%x& lPacketLen=%d&key1 = %s&key2 = %s&len=%d&data=%s
&userkey=%s&historyflag=%s&data=%s      encode=1&data=%s
```

字段: `si`(服务), `qsid`(会话), `dlzh`(登录账号), `yybrid`(营业部), `key1/key2`(密钥), `ret`(返回码), `data`(载荷)。

### 操作命令

- 下单: `cmd=xd_mairu`(买入)、`cmd=xd_maichu`(卖出)、`cmd=xd_dmdm`、`cmd=cmd_qu_zijin`(查资金)
- 港股通 `ex_cmd=`: `ggt_mairu/ggt_maichu`(买/卖)、`ggt_cd`、`ggt_query_drwt/chengjiao/zijin/cican/kcwt/jiacha`、`query_ggt_kmsl`(可买数量)、`query_ggt_bd_info`
- 参数 `ex_`: `ex_zqdm`(代码) `ex_wtjg`(价) `ex_wtsl`(量) `ex_mmlb`(买卖类别) `ex_gdzh`(股东) `ex_htbh`(合同号) `ex_kyye`(可用) `ex_scdm`(市场) `ex_czlb`(操作类别)
- 内部: `tjdd_upload_wt`(提交委托) `tjdd_chedan`(撤单) `tjdd_order` `tjdd_cx_dd` `tjdd_cx_gpxx` `tjdd_extend` `tjdd_change`
- 通用交易字段: `wtjg wtsl jylx jysc mmlb txmm jymm khh yyb zjzh zqdm zqzh htbh cjsl wtfs`
- CEF↔原生桥: `&func=DataPoolNew.SetData&retcode=%d&type=%0x&cmd=%s&seq=%d` + `ex_xd_local_call_flag/guid`

### 委托程序体系

- `weituonew.exe`: 券商委托程序安装器（装 `xiadan.exe`、`zyyjy.exe` 等，安装目录 `C:\Program Files\weituo\`）
- `embeddedtrade.dll`(6.5MB): 主客户端内嵌交易，导出 `OnStartET/CloseET/ShowET/SetCallback/OnNotify/OnSetCurUser/OnRecvXgXzInfo...`，走窗口消息回调
- `thosttraderapi.dll`/`thostmduserapi.dll`: 上期技术 CTP 期货 API（`CThostFtdcTraderApi::CreateFtdcTraderApi`），期货交易直接对接券商 CTP 前置
- 相关脚本: `tradeupdate.bat`（下单程序升级）、`copytrade.bat`

## 2.2 下单相关 UI 资源（佐证功能面）

`skin/tradeWindow/fusionDisplay.xml`（字直接提交委托）、`skin/tradeTrack.xml`（委托/撤单列表）、`html/weituo/`（普通/融资融券/港股美股委托页, 券商列表 `dsfwt.10jqka.com.cn/dealerlist/rzrq.html|ggmg.html`）、`html/strategy/`（期权策略下单, `thsOption.callxiadan`）、`html/shortKey/`（快捷下单键位）。
